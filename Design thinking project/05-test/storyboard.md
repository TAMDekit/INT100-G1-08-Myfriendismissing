## เรื่องราวของ "นุ่น" — หลังมี SiamQ 🎉

### ฉาก 1: จุดเริ่มต้น (เหมือนเดิม)
```
┌─────────────────────────────────────────────┐
│  🏠  นุ่นนั่งอยู่ที่บ้าน หิวมาก              │
│      เห็นรีวิวร้านอาหารในสยามสแควร์          │
│                                             │
│  💭 "อยากกิน! เช็ค SiamQ ก่อนดีกว่า"        │
└─────────────────────────────────────────────┘
```

### ฉาก 2: เช็ค SiamQ ก่อนออกจากบ้าน 📱
```

│  📱  นุ่นเปิด SiamQ บนมือถือ                │
│      เห็นร้านที่อยากไป: "คิว 3 คน (~10 นาที)" │
│      ดูเมนูล่วงหน้า: ราคาโอเค!              │
│                                             │
│  💭 "10 นาที ไม่นานเลย จองเลย!"             │
│  👆 [จองคิว] ← กดจอง                       │
```

## 📊 เปรียบเทียบ Before vs After

| ประเด็น | ❌ Before SiamQ | ✅ After SiamQ |
|---|---|---|
| **เวลาที่เสีย** | 30–60 นาทีเดินหาร้าน | 0 นาที (จองล่วงหน้า) |
| **อารมณ์** | Hangry, หงุดหงิด | สบายใจ, มีความสุข |
| **ผลลัพธ์** | กินร้านที่ไม่ได้อยากกิน | กินร้านที่ต้องการ |
| **ประสบการณ์** | เสียอารมณ์ทั้งวัน | Happy dining! |
| **การกลับมา** | "ไม่มาสยามอีก" | "มาอีกแน่ ๆ!" |
