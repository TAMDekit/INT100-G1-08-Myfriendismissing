# 📝 Test Script — สคริปต์การทดสอบกับผู้ใช้

> **โครงงาน:** รายงานการวิเคราะห์พฤติกรรมผู้บริโภคย่านสยามสแควร์ (Siam Square Dining Habits)  
> **โซลูชัน:** SiamQ — ระบบจัดการคิวอัจฉริยะ  
> **จำนวนผู้ทดสอบ:** 5 คน  
> **สถานที่:** ย่านสยามสแควร์ / ออนไลน์

---

## วัตถุประสงค์ของการทดสอบ

1. ตรวจสอบว่าผู้ใช้สามารถใช้งาน SiamQ ได้อย่างเข้าใจและรวดเร็วหรือไม่
2. ประเมินว่าฟีเจอร์ต่าง ๆ ตอบโจทย์ Pain Point จริงหรือไม่
3. รวบรวม Feedback เพื่อนำไปปรับปรุง Prototype

---

## รูปแบบการทดสอบ

| รายละเอียด | ข้อมูล |
|---|---|
| **ประเภท** | Usability Testing (Moderated) |
| **ระยะเวลา** | 15–20 นาที / คน |
| **อุปกรณ์** | สมาร์ทโฟน (เว็บเบราว์เซอร์) |
| **การบันทึก** | จดบันทึก + สังเกตพฤติกรรม |

---

## สคริปต์การทดสอบ

### Part 1: บทนำ (2 นาที)

> *"สวัสดีครับ/ค่ะ ขอบคุณที่มาช่วยทดสอบนะคะ วันนี้เราอยากให้ลองใช้เว็บแอปที่ชื่อ SiamQ ซึ่งเป็นระบบจัดการคิวร้านอาหารในสยามสแควร์ ไม่มีคำตอบถูกผิดนะคะ เราอยากรู้ความคิดเห็นจริง ๆ ของคุณ ถ้ามีตรงไหนสงสัยหรือไม่เข้าใจก็พูดออกมาได้เลยค่ะ"*

### Part 2: Task-based Testing (10 นาที)

#### Task 1: ค้นหาร้านอาหาร
> *"สมมติว่าคุณหิวมากและอยากหาร้านอาหารในสยามสแควร์ ลองเปิดเว็บแอปแล้วหาร้านที่คุณสนใจดูนะคะ"*

**สิ่งที่สังเกต:**
- [ ] ผู้ใช้เข้าใจวิธีเริ่มต้นใช้งานหรือไม่?
- [ ] ใช้เวลานานแค่ไหนในการหาร้าน?
- [ ] มีจุดไหนที่สับสนหรือไม่?

#### Task 2: ดูสถานะคิว
> *"ลองดูว่าร้านที่คุณสนใจมีคิวนานแค่ไหน"*

**สิ่งที่สังเกต:**
- [ ] ผู้ใช้เข้าใจข้อมูลสถานะคิวหรือไม่?
- [ ] ข้อมูลชัดเจนเพียงพอหรือไม่?
- [ ] อยากเห็นข้อมูลเพิ่มเติมอะไรอีก?

#### Task 3: จองคิว
> *"ถ้าคุณตัดสินใจจะกินร้านนี้ ลองจองคิวดูนะคะ"*

**สิ่งที่สังเกต:**
- [ ] ผู้ใช้หาปุ่มจองคิวเจอไหม?
- [ ] ขั้นตอนการจองเข้าใจง่ายหรือไม่?
- [ ] ผู้ใช้พอใจกับ Confirmation ที่ได้รับหรือไม่?

#### Task 4: ดูเมนูและราคา (v2)
> *"ก่อนไปร้าน ลองดูเมนูและราคาก่อนได้ไหม?"*

**สิ่งที่สังเกต:**
- [ ] ผู้ใช้หาเมนูเจอง่ายไหม?
- [ ] ข้อมูลราคาเพียงพอต่อการตัดสินใจหรือไม่?

### Part 3: Post-test Interview (5 นาที)

1. *"ความรู้สึกโดยรวมเป็นอย่างไรบ้างคะ?"*
2. *"ถ้ามี SiamQ ใช้จริง ๆ จะใช้ไหม? ทำไม?"*
3. *"มีอะไรที่อยากให้เปลี่ยนหรือเพิ่มไหม?"*
4. *"ถ้าให้คะแนน 1–5 ความง่ายในการใช้งาน จะให้เท่าไหร่?"*
5. *"ฟีเจอร์ไหนที่ชอบที่สุด? และไม่ชอบที่สุด?"*

### Part 4: ปิดท้าย (1 นาที)

> *"ขอบคุณมากนะคะที่สละเวลามาช่วยทดสอบ Feedback ของคุณจะช่วยให้เราพัฒนา SiamQ ให้ดีขึ้นค่ะ"*

---

## 📋 Evaluation Criteria

| เกณฑ์ | คำอธิบาย | วิธีวัด |
|---|---|---|
| **Effectiveness** | ผู้ใช้ทำ Task สำเร็จหรือไม่ | อัตราความสำเร็จ (%) |
| **Efficiency** | ทำ Task ได้เร็วแค่ไหน | เวลาที่ใช้ (วินาที) |
| **Satisfaction** | ผู้ใช้พอใจแค่ไหน | คะแนน 1–5 |
| **Learnability** | เรียนรู้วิธีใช้งานง่ายไหม | จำนวนครั้งที่ต้องช่วยเหลือ |
| **Error Rate** | มีข้อผิดพลาดกี่ครั้ง | จำนวนข้อผิดพลาด |
