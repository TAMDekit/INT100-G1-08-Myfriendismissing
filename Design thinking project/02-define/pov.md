# 🎯 Point of View (PoV) Statement

> **โครงงาน:** รายงานการวิเคราะห์พฤติกรรมผู้บริโภคย่านสยามสแควร์ (Siam Square Dining Habits)  
> **ที่มา:** สังเคราะห์จาก Insights, 5 Whys, Empathy Map และ Journey Map

---

## PoV Statement Format

**[USER]** needs a way to **[USER'S NEED]** because **[SURPRISING INSIGHT]**

---

## PoV Statement หลัก

> ### 🎯 PoV Statement
> 
> **นักศึกษาและคนรุ่นใหม่ที่มากินอาหารในย่านสยามสแควร์**  
> ต้องการวิธีที่จะ **รู้สถานะคิวของร้านอาหารล่วงหน้าและจัดการเวลารอได้อย่างมีประสิทธิภาพ**  
> เพราะ **ปัญหาหลักไม่ใช่ "คิวยาว" แต่คือ "ไม่รู้ว่าจะต้องรอนานแค่ไหน" ซึ่งทำให้เกิดภาวะ Hangry (หิว + หงุดหงิด) ที่ทำลายประสบการณ์การกินทั้งหมด**

---

## องค์ประกอบของ PoV

### 👤 USER — ใครคือผู้ใช้ของเรา?

| คุณลักษณะ | รายละเอียด |
|---|---|
| **กลุ่มเป้าหมาย** | นักศึกษา / คนรุ่นใหม่ อายุ 18–25 ปี |
| **สถานที่** | ย่านสยามสแควร์ กรุงเทพมหานคร |
| **พฤติกรรม** | มากินอาหารเป็นประจำ ใช้โซเชียลมีเดียหาร้าน |
| **บุคลิก** | ให้ความสำคัญกับเวลาและความคุ้มค่า |

### 💎 NEED — ผู้ใช้ต้องการอะไร?

1. **รู้ข้อมูลคิวล่วงหน้า** — ก่อนเดินไปถึงหน้าร้าน
2. **จัดการเวลารอได้** — ถ้าต้องรอ อยากรู้ว่ากี่นาที
3. **ประสบการณ์รอที่ดีขึ้น** — ไม่ใช่แค่ยืนรอเปล่า ๆ
4. **ข้อมูลราคา-คุณภาพที่โปร่งใส** — เปรียบเทียบก่อนเลือก

### 💡 INSIGHT — ข้อค้นพบที่น่าประหลาดใจ

> **"ผู้บริโภคไม่ได้เกลียดการรอ — แต่เกลียดความไม่แน่นอนของการรอ"**

- คนที่มากับเพื่อนยอมรอได้ → แสดงว่า "เวลา" ไม่ใช่ปัญหาที่แท้จริง
- ทุกคนเล่นมือถือฆ่าเวลา → ต้องการ Distraction ไม่ใช่ความเร็ว
- ยอมจ่ายแพงเพื่อ "ประสบการณ์" → ให้คุณค่า "ความรู้สึก" มากกว่า "อาหาร"

## PoV Statements เสริม

### PoV 2: มุมมองด้านราคา
> **ผู้บริโภครุ่นใหม่ในสยามสแควร์** ต้องการ **ข้อมูลที่โปร่งใสเปรียบเทียบราคาและคุณภาพร้านอาหาร** เพราะ **พวกเขาไม่ได้ปฏิเสธการจ่ายแพง แต่ต้องการรู้สึกว่า "คุ้มค่า" ทั้งทางร่างกาย (อร่อย/อิ่ม) และทางจิตใจ (ประสบการณ์/ความภูมิใจ)**

### PoV 3: มุมมองด้านสังคม
> **คนที่มากินอาหารคนเดียวในสยามสแควร์** ต้องการ **ทางเลือกที่ไม่ต้องยืนรอคิวลำพัง** เพราะ **บริบทสังคม (มีเพื่อน vs มาคนเดียว) ส่งผลอย่างมากต่อความอดทนในการรอ และประสบการณ์โดยรวม**

---

## 🔗 PoV → HMW (How Might We)

PoV Statement นี้จะถูกนำไปสร้างคำถาม **How Might We** ในขั้นตอนถัดไป เพื่อกำหนดทิศทางการ Ideate

```
PoV Statement
     │
     ▼
How Might We...?
     │
     ▼
Brainstorming Ideas
     │
     ▼
Prototype Solution
```
