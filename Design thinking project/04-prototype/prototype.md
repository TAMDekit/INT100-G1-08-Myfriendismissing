# 🔧 Prototype — อธิบาย Prototype / Versions

> **โครงงาน:** รายงานการวิเคราะห์พฤติกรรมผู้บริโภคย่านสยามสแควร์ (Siam Square Dining Habits)  
> **โซลูชัน:** SiamQ — ระบบจัดการคิวอัจฉริยะสำหรับย่านสยามสแควร์

---

## ภาพรวม Prototype

SiamQ ถูกพัฒนาเป็น 2 เวอร์ชัน (Iterative Design) โดยเวอร์ชัน 2 ปรับปรุงจาก Feedback ของผู้ใช้ที่ทดสอบเวอร์ชัน 1

---

## Version 1 (v1) — MVP (Minimum Viable Product)

### 📋 ฟีเจอร์ที่รวมอยู่

| ฟีเจอร์ | รายละเอียด | สถานะ |
|---|---|---|
| **หน้าแรก (Landing Page)** | แนะนำ SiamQ พร้อมปุ่ม "ดูร้านอาหาร" | ✅ |
| **รายชื่อร้านอาหาร** | แสดงร้านอาหารในสยามสแควร์ พร้อมสถานะคิว | ✅ |
| **ข้อมูลสถานะคิว** | แสดงจำนวนคิวที่กำลังรอ + เวลาโดยประมาณ | ✅ |
| **ปุ่มจองคิว** | กดจองคิวออนไลน์ ได้รับหมายเลขคิว | ✅ |

### 🛠️ เทคโนโลยี
- HTML5 / CSS3 / JavaScript
- Responsive Design (Mobile-first)
- ไม่ต้องใช้ Backend (ข้อมูลจำลองใน JavaScript)

### 📂 โครงสร้างไฟล์
```
v1/
├── index.html    # หน้าหลักของเว็บแอป
├── style.css     # สไตล์และการจัดวาง
└── script.js     # ลอจิกการทำงาน
```

## Version 2 (v2) — Improved Version

### 📋 สิ่งที่ปรับปรุงจาก v1

| สิ่งที่ปรับปรุง | v1 | v2 |
|---|---|---|
| **ดีไซน์** | พื้นฐาน | ปรับปรุง UI/UX ให้สวยงามและใช้งานง่ายขึ้น |
| **ข้อมูลร้าน** | แสดงชื่อ + สถานะคิว | เพิ่มเมนูแนะนำ + ช่วงราคา + คะแนนรีวิว |
| **ระบบค้นหา** | ไม่มี | เพิ่มระบบค้นหาและกรองร้านตามประเภท/ราคา |
| **การแจ้งเตือน** | ไม่มี | เพิ่มระบบแจ้งเตือนเมื่อใกล้ถึงคิว (Notification) |
| **Feedback จากผู้ใช้** | - | ปรับตาม Feedback จาก User Testing |

### 📂 โครงสร้างไฟล์
```
v2/
├── index.html    # หน้าหลักที่ปรับปรุงแล้ว
├── style.css     # สไตล์ที่ปรับปรุงแล้ว
└── script.js     # ลอจิกที่เพิ่มฟีเจอร์
```

## 🎯 Design Principles

1. **Mobile-First:** ออกแบบสำหรับมือถือเป็นหลัก เพราะผู้ใช้ใช้มือถือขณะอยู่ในสยามสแควร์
2. **Speed:** โหลดเร็ว ใช้งานง่าย ไม่ต้องสมัครสมาชิก
3. **Clarity:** ข้อมูลสถานะคิวต้องเด่นชัด อ่านได้ทันที
4. **Delight:** มีแอนิเมชั่นเล็ก ๆ ที่ทำให้รู้สึกดีขณะใช้งาน
