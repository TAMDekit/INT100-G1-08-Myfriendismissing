# 👤 User Persona

> **โครงงาน:** รายงานการวิเคราะห์พฤติกรรมผู้บริโภคย่านสยามสแควร์ (Siam Square Dining Habits)  
> **ที่มา:** สังเคราะห์จากข้อมูลสัมภาษณ์เชิงลึก 7 คน

---

## Persona: "น้องนุ่น" — นักศึกษาสายฟู้ดดี้ย่านสยาม

### ข้อมูลพื้นฐาน

| รายละเอียด | ข้อมูล |
|---|---|
| **ชื่อ** | นุ่น (สมมติ) |
| **อายุ** | 19–22 ปี |
| **อาชีพ** | นักศึกษาระดับมหาวิทยาลัย |
| **รายได้** | ค่าขนมจากผู้ปกครอง + รายได้เสริมจากงานพาร์ทไทม์ |
| **ที่อยู่** | กรุงเทพมหานคร / ปริมณฑล |
| **การเดินทาง** | BTS / รถไฟฟ้า เป็นหลัก |

---

### 🎯 เป้าหมาย (Goals)

1. **หาร้านอาหารอร่อย ราคาไม่แพง** ในย่านสยามสแควร์ที่เข้าถึงได้ง่าย
2. **ไม่ต้องเสียเวลารอคิวนาน** — ต้องการกินได้เร็ว โดยเฉพาะเวลาหิวจัด
3. **ได้ลองร้านใหม่ / ร้านดัง** ตามเทรนด์โซเชียลเป็นครั้งคราว
4. **สร้างประสบการณ์การกินที่ดี** กับเพื่อนหรือคนรัก

---

### 😩 Pain Points (ปัญหาที่เจอ)

1. **คิวยาวเกินทน** — ร้านดัง ๆ มักมีคิวหนาแน่น ทำให้ต้องเดินหนีไปร้านอื่น
2. **Hangry Effect** — ยิ่งหิวยิ่งหงุดหงิด การรอคิวทำให้อารมณ์เสียมากขึ้น
3. **Overpriced** — หลายร้านตั้งราคาสูงเกินคุณภาพวัตถุดิบจริง
4. **ไม่มีข้อมูลคิวล่วงหน้า** — ต้องเดินไปถึงหน้าร้านถึงจะรู้ว่าคิวยาว
5. **มาคนเดียวยิ่งทรมาน** — รอคิวคนเดียวไม่มีเพื่อนคุย รู้สึกแย่กว่าเดิม

---

### 💭 แรงจูงใจ (Motivations)

| ประเภท | รายละเอียด |
|---|---|
| **🔥 FOMO (Fear of Missing Out)** | อยากลองร้านดังที่โซเชียลกำลังพูดถึง ไม่อยากตกเทรนด์ |
| **🎁 Self-Reward** | บางครั้งอยากปรนเปรอตัวเองด้วยอาหารดี ๆ เป็น "รางวัลชีวิต" |
| **❤️ Fan Support** | ยอมจ่ายแพงเพื่ออุดหนุนแบรนด์ดารา/อินฟลูเอนเซอร์ที่ชื่นชอบ |
| **👥 Social Bonding** | การกินข้าวกับเพื่อน/แฟนเป็นกิจกรรมสร้างความสัมพันธ์ |
| **💰 Value for Money** | ต้องการความคุ้มค่า — คุณภาพวัตถุดิบ + ปริมาณ ต้องสมราคา |

- ติดตามเทรนด์อาหารและดารา/อินฟลูเอนเซอร์
