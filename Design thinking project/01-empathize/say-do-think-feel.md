# 🗣️ Say – Do – Think – Feel (Empathy Map)

> **โครงงาน:** รายงานการวิเคราะห์พฤติกรรมผู้บริโภคย่านสยามสแควร์ (Siam Square Dining Habits)  
> **กรอบการวิเคราะห์:** Empathy Map — Say, Do, Think, Feel  
> **วัตถุประสงค์:** สร้างแผนผังความเข้าใจผู้ใช้แบบรอบด้าน

---

## 💬 SAY — สิ่งที่ผู้ใช้พูดออกมา

สิ่งที่ผู้ให้สัมภาษณ์พูดออกมาตรง ๆ ระหว่างการสัมภาษณ์:

| ผู้ให้สัมภาษณ์ | คำพูด |
|---|---|
| คนที่ 1 | *"ท้าทายดีค่ะ แต่ไม่รอดีกว่า"* |
| คนที่ 2 | *"ไม่เข้าค่ะ ถ้าคิวยาวไม่เข้า"* |
| คนที่ 6 | *"ยิ่งรอนานมันก็ยิ่งหิว แล้วมันรู้สึกไม่ดี"* |
| คนที่ 7 | *"อร่อยจริงก็คิดว่าเป็นบาทนึงที่จะตอบแทนชีวิต"* |
| คนที่ 6 | *"ถ้าวัตถุดิบธรรมดาแต่ขายราคาสูง คือ Overpriced"* |
| คนที่ 4 | *"มาคนเดียวไม่มีใครช่วยแชร์เวลาคอย ไม่ควรยอมรอแถวยาวเด็ดขาด"* |

---

## 🏃 DO — สิ่งที่ผู้ใช้ปฏิบัติจริง

พฤติกรรมที่สังเกตเห็นได้จากการกระทำจริง:

- 🚶 **เดินเลี้ยวหนีออกจากหน้าร้าน** เมื่อเห็นคนแออัด
- 📱 **ก้มหน้าก้มตาเล่นสมาร์ทโฟน** ไถ TikTok และโซเชียลมีเดีย
- 💬 **ปรับทุกข์ พูดคุยเสียงเบา** กับคนรักหรือกลุ่มเพื่อน
- 🏪 **เลือกเดินไปหาร้านราคาถูกข้างนอก** เพื่อเซฟงบ (ย่านสวนหลวง)
- 💸 **ยอมควักเงินจ่ายของหวานราคาแพงในวันพิเศษ** (เจลาโต้, ร้านดัง)

---

## 🧠 THINK — สิ่งที่ผู้ใช้น่าจะคิด

ความคิดภายในที่วิเคราะห์ได้จากบริบทการสนทนา:

- 🤔 *"การยืนรอคิวนาน ๆ แลกกับอาหารจานเดียว เป็นการทรมานร่างกายโดยไม่จำเป็น"*
- 😤 *"ร้านอาหารบางร้านฉวยโอกาสตั้งราคาสูงเกินคุณภาพวัตถุดิบเพื่อเอาเปรียบเรา"*
- 🎁 *"การเปย์อาหารแบรนด์ดาราหรือเจลาโต้ ช่วยให้จิตใจของเรามีความสุข ได้รางวัล"*
- 😔 *"มาคนเดียวไม่มีใครช่วยแชร์เวลาคอย ไม่ควรยอมรอแถวยาวเด็ดขาด"*

---

## ❤️ FEEL — ความรู้สึกที่สัมผัสได้

อารมณ์และความรู้สึกที่ผู้ใช้แสดงออกมาทั้งทางตรงและทางอ้อม:

| อารมณ์ | รายละเอียด |
|---|---|
| 😡 **หงุดหงิด โมโหหิว (Hangry)** | รู้สึกไม่ดีอย่างยิ่งและหงุดหงิดเมื่อท้องร้องแล้วคิวไม่ขยับ |
| 😤 **อึดอัด คับข้องใจ** | รู้สึกถูกบังคับให้ยืนรอคิว จนรู้สึกรุ่มร้อนอยู่ในใจลึก ๆ (*"อุ่นอยู่ในใจ"*) |
| 😌 **เพลิดเพลินชั่วคราว** | อารมณ์ดีขึ้นเมื่อมีเพื่อนคุยหรือมี TikTok ช่วยดึงสายตา |
| 😊 **มีความสุขปนภูมิใจ** | รู้สึกดีที่ได้รับประทานอาหารที่ดีเพื่อเยียวยาจิตใจตนเอง |

---

## 📊 Empathy Map Quadrant (แผนผัง)

```
┌───────────────────────────────┬───────────────────────────────┐
│         💬 SAY                │         🏃 DO                 │
│                               │                               │
│ • "ท้าทายดี แต่ไม่รอดีกว่า"   │ • เดินหนีจากหน้าร้านที่แออัด  │
│ • "คิวยาวไม่เข้าเด็ดขาด"     │ • ก้มหน้าเล่นมือถือ           │
│ • "ยิ่งรอนาน ยิ่งหิว"         │ • คุยกับเพื่อน/แฟนฆ่าเวลา    │
│ • "รางวัลชีวิต ตอบแทนตัวเอง" │ • ยอมจ่ายแพงในวันพิเศษ       │
│ • "Overpriced ถ้าวัตถุดิบ     │ • หาร้านราคาถูกนอกห้าง       │
│   ธรรมดา"                     │                               │
├───────────────────────────────┼───────────────────────────────┤
│         🧠 THINK              │         ❤️ FEEL               │
│                               │                               │
│ • รอคิวนาน = ทรมานร่างกาย    │ • หงุดหงิด โมโหหิว (Hangry)   │
│ • บางร้านฉวยโอกาสเอาเปรียบ   │ • อึดอัด คับข้องใจ            │
│ • เปย์ = รางวัลจิตใจ         │ • เพลิดเพลินชั่วคราว          │
│ • มาคนเดียว ≠ รอคิว          │ • มีความสุข + ภูมิใจ          │
│                               │   เมื่อได้กินของดี             │
└───────────────────────────────┴───────────────────────────────┘
```
