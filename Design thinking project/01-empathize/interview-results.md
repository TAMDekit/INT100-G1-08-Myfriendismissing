# 📊 Interview Results — สรุปผลสัมภาษณ์รายบุคคล

> **โครงงาน:** รายงานการวิเคราะห์พฤติกรรมผู้บริโภคย่านสยามสแควร์ (Siam Square Dining Habits)  
> **จำนวนผู้ให้สัมภาษณ์:** 7 คน  
> **สถานที่สัมภาษณ์:** ย่านสยามสแควร์ กรุงเทพมหานคร

## ผู้ให้สัมภาษณ์คนที่ 1 (Siam Square 2.m4a)

| หัวข้อ | รายละเอียด |
|---|---|
| **ความชอบ** | ชื่นชอบอาหารญี่ปุ่นเป็นหลัก |
| **การรอคิว** | มองว่าท้าทายดี แต่ปัดตกและเลือกที่จะไม่รอคิวหน้าร้านเพื่อความสะดวก |
| **พฤติกรรมระหว่างรอ** | เล่นโทรศัพท์มือถือ |
| **ราคาและความคุ้มค่า** | ยินดีจ่ายแพงหากเป็นอาหารที่สามารถทดลองกินได้สักครั้งในชีวิตเพื่อดูว่าชอบหรือไม่ หากลองแล้วชอบคิดว่าคุ้มค่าเงินก็จะไปกินต่อ แต่ถ้าไม่ชอบก็แค่ไม่กินซ้ำอีก |

## สรุปภาพรวมผลสัมภาษณ์ (Overview Summary)

| ประเด็น | ข้อค้นพบหลัก |
|---|---|
| **ความชอบอาหาร** | หลากหลาย — อาหารญี่ปุ่น, ต้มยำ, ตามสั่ง, ปิ้งย่าง, ชาบู/บุฟเฟ่ต์, ร้านริมทาง |
| **ทัศนคติต่อการรอคิว** | **ส่วนใหญ่ปฏิเสธ** — 6/7 คนจะไม่รอคิวยาว, เพียง 1 คนยอมรอบ้างหากเมนูโปรด |
| **พฤติกรรมระหว่างรอ** | **เล่นมือถือ** (6/7 คน) — TikTok, Facebook, IG; พูดคุยกับคนร่วมทาง (2/7 คน) |
| **ราคาและความคุ้มค่า** | **ปฏิเสธ Overpriced** แต่มี "ข้อยกเว้น" — ทดลองร้านดัง, อุดหนุนดารา, รางวัลชีวิต |
| **บริบทสังคม** | มากับเพื่อน/แฟน = อดทนรอได้มากขึ้น; มาคนเดียว = ไม่รอเด็ดขาด |
