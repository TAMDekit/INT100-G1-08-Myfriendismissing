# 🗺️ Journey Map — แผนที่ประสบการณ์ผู้ใช้

> **โครงงาน:** รายงานการวิเคราะห์พฤติกรรมผู้บริโภคย่านสยามสแควร์ (Siam Square Dining Habits)  
> **Persona:** น้องนุ่น — นักศึกษาสายฟู้ดดี้  
> **สถานการณ์:** การเดินทางมากินอาหารในย่านสยามสแควร์

---

## รายละเอียดแต่ละขั้นตอน

### ขั้นตอนที่ 1: ก่อนออกจากบ้าน 🏠

```
อารมณ์: 😊 ตื่นเต้น
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

- **กิจกรรม:** ไถ TikTok / IG ดูรีวิวร้านอาหาร, นัดเพื่อนผ่าน LINE
- **ความคิด:** *"วันนี้กินอะไรดี ร้านไหนกำลังดังนะ"*
- **Pain Point:** ข้อมูลรีวิวล้นมากจนเลือกไม่ถูก, ไม่รู้ว่าร้านจะคิวยาวหรือไม่
- **โอกาส:** 💡 ระบบแนะนำร้านตามความชอบ + แสดงสถานะคิว Real-time

---

### ขั้นตอนที่ 2: เดินทางมาถึงสยามสแควร์ 🚇

```
อารมณ์: 😐 → 😟 เริ่มหิว
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

- **กิจกรรม:** ลง BTS สยาม, เดินเข้าพื้นที่สยามสแควร์
- **ความคิด:** *"หิวแล้ว อยากกินเร็ว ๆ"*
- **Pain Point:** เดินร้อน, ไม่รู้ทิศทางว่าร้านไหนอยู่ตรงไหน
- **โอกาส:** 💡 แผนที่ร้านอาหารในพื้นที่ + ระบบนำทาง

---

### ขั้นตอนที่ 3: เลือกร้านอาหาร 👀

```
อารมณ์: 😕 กังวล / ผิดหวัง
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

- **กิจกรรม:** เดินดูหน้าร้านหลายร้าน, มองจำนวนคิว, ดูป้ายราคาเมนู
- **ความคิด:** *"คิวยาวจัง ไปร้านอื่นดีกว่า"* / *"ร้านนี้แพงไปมั้ย"*
- **Pain Point:** ⚡ **จุดเจ็บปวดหลัก** — เห็นคิวยาวแล้วต้องเดินเลี่ยง ซ้ำไปหลายร้าน เสียเวลา
- **โอกาส:** 💡 ระบบจองคิวออนไลน์ล่วงหน้า / แจ้งเตือนเมื่อใกล้ถึงคิว

---

### ขั้นตอนที่ 4: รอคิว ⏰

```
อารมณ์: 😡 หงุดหงิด (Hangry) — จุดต่ำสุด
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

- **กิจกรรม:** ยืนรอหน้าร้าน, เล่นมือถือ, คุยกับเพื่อน/แฟน
- **ความคิด:** *"เมื่อไหร่จะถึงคิวเรา"* / *"ทรมานจัง ไม่น่ามา"*
- **Pain Point:** ⚡ **จุดวิกฤตที่สุด** — ความหิว + ความร้อน + ไม่รู้ว่าต้องรออีกนานเท่าไหร่ = Hangry
- **โอกาส:** 💡 ระบบคิวดิจิทัล + แจ้งเวลาคาดการณ์ + กิจกรรมให้ทำระหว่างรอ

---

### ขั้นตอนที่ 5: สั่งอาหารและกิน 🍽️

```
อารมณ์: 😋 พอใจ / 😤 ผิดหวัง (ถ้าไม่คุ้ม)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

- **กิจกรรม:** สั่งอาหาร, ถ่ายรูปลง IG, ทานอาหาร
- **ความคิด:** *"อร่อยดี คุ้มที่รอ"* หรือ *"ไม่คุ้มราคาเลย Overpriced"*
- **Pain Point:** อาหารไม่ถึงความคาดหวัง / ปริมาณน้อยไม่สมราคา
- **โอกาส:** 💡 ระบบรีวิวที่ช่วยตั้งความคาดหวังก่อนกิน

---

### ขั้นตอนที่ 6: หลังกิน 🧾

```
อารมณ์: 😊 / 😞 แล้วแต่ประสบการณ์
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

- **กิจกรรม:** จ่ายเงิน, โพสต์รีวิวลงโซเชียล, ตัดสินใจว่าจะกลับมาอีกหรือไม่
- **ความคิด:** *"กลับมาอีกแน่ ๆ"* หรือ *"ไม่มาอีกแล้ว"*
- **Pain Point:** ไม่มีช่องทางให้ feedback ร้านโดยตรง
- **โอกาส:** 💡 ระบบ feedback + สะสมแต้ม/คูปอง

## 🔑 Key Insight จาก Journey Map

> **"ช่วงเวลารอคิว" คือจุดวิกฤตที่สร้างประสบการณ์เชิงลบมากที่สุด**  
> หากสามารถแก้ปัญหาการรอคิวได้ จะเปลี่ยนแปลงประสบการณ์ทั้งหมดของผู้ใช้ในย่านสยามสแควร์ได้อย่างมีนัยสำคัญ
